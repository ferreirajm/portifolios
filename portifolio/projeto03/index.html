HTML

O HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é a linguagem padrão usada para criar e estruturar páginas na internet. Ele funciona como o esqueleto de um site, organizando textos, imagens, links e outros elementos para que o navegador consiga exibi-los corretamente.O que o HTML fazDefine a estrutura básica de um site.Organiza conteúdos como títulos, parágrafos, listas e tabelas.Insere elementos visuais e mídias, como imagens, vídeos e áudios.Cria conexões por meio de hiperlinks para navegar entre páginas.Como ele funcionaO HTML não é uma linguagem de programação, mas sim de marcação. Isso significa que ele usa códigos chamados tags (marcadores entre os sinais < e >) para dizer ao navegador o que cada parte do conteúdo significa.A estrutura de um documento é dividida principalmente em:<"html">: o elemento raiz que envolve todo o código.<"head">: guarda as informações de configuração e o título da página.<"body">: contém todo o conteúdo visível para o usuário.Tecnologias associadasO HTML sozinho define apenas o conteúdo bruto. Para criar sites modernos e completos, ele trabalha junto com outras duas ferramentas essenciais:CSS: cuida do estilo, cores, fontes e do visual da página.JavaScript: adiciona dinamismo e interatividade

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é a linguagem usada para estilizar e dar identidade visual às páginas da internet. Enquanto o HTML cria a estrutura física e o esqueleto de um site, o CSS cuida de toda a parte estética, como cores, fontes, layouts e espaçamentos.O que o CSS fazAltera as cores de fundos, textos, bordas e links.Define os tipos de letra, tamanhos e alinhamentos dos textos.Controla o layout da página, como o posicionamento de colunas e imagens.Garante o design responsivo, adaptando o site para celulares e computadores.Cria animações e efeitos de transição visual nos elementos.Como ele funcionaO CSS funciona por meio de regras que selecionam uma tag do HTML e aplicam propriedades específicas a ela. Cada regra tem um seletor e uma declaração.Veja a anatomia básica de um código CSS:cssp { color: blue; font-size: 16px;} Use o código com cuidado.p: o seletor que indica que a regra será aplicada a todos os parágrafos. color: blue;: a propriedade e o valor que mudam a cor do texto para azul.font-size: 16px;: a propriedade e o valor que definem o tamanho da letra.Por que o termo "Em Cascata"?O nome "em cascata" refere-se à forma como o navegador lê e aplica as regras visuais. Se existirem duas regras diferentes para o mesmo elemento, o navegador segue uma ordem de prioridade (hierarquia). Geralmente, a regra mais específica ou a que foi escrita por último na folha de estilo é a que prevalece.Para entender a fundo como estilizar suas páginas, você pode consultar o guia completo de CSS na MDN Web Docs.

JavaScript

O JavaScript (ou JS) é uma linguagem de programação usada para tornar as páginas da internet dinâmicas e interativas. Enquanto o HTML cria o esqueleto do site e o CSS define o visual, o JavaScript funciona como o cérebro, controlando o comportamento da página em tempo real.O que o JavaScript fazCria elementos interativos como menus, carrosséis e botões inteligentes.Atualiza partes da página sem precisar recarregar o site inteiro.Cria animações complexas, jogos e gráficos em 2D ou 3D.Valida as informações de um formulário antes de enviá-las.Carrega novos dados de servidores em segundo plano (como o feed do seu Instagram).Como ele funcionaO JavaScript é processado diretamente pelo navegador do usuário (no navegador de internet, como Chrome ou Firefox). Ele consegue ler e modificar os elementos do HTML e as regras do CSS enquanto você navega.Veja um exemplo simples de código que exibe uma mensagem na tela:
javascriptlet botao = document.querySelector('button'); botao.addEventListener('click', function()){ alert('Você clicou no botão e ativou o JavaScript!'); };
O Trio do Desenvolvimento WebPara entender a importância dele, pense na criação de um site como a construção de um carro:HTML: É o chassi, as rodas e a estrutura do veículo.CSS: É a pintura, o modelo dos bancos e o design do painel.JavaScript: É o motor, a parte elétrica e o sistema que faz tudo funcionar.Hoje o JavaScript também é usado fora dos navegadores para criar aplicativos de celular, programas de computador e servidores inteiros. Para explorar todo o potencial da linguagem, você pode ler o guia oficial na MDN Web Docs.

Internet

A internet é uma rede global de computadores interconectados que trocam informações entre si. Ela funciona como a infraestrutura física e lógica mundial que permite que dispositivos no mundo todo — como computadores, celulares e servidores — conversem e compartilhem dados instantaneamente.O que ela fazConecta bilhões de dispositivos ao redor do planeta.Permite o envio de mensagens, e-mails e chamadas de vídeo.Viabiliza o streaming de filmes, músicas e jogos online.Armazena e distribui arquivos em sistemas de nuvem.Como ela funcionaA internet não funciona por satélite na maior parte do tempo, mas sim por cabos. Os dados viajam pelo mundo através de uma gigantesca rede subterrânea e submarina de cabos de fibra óptica.Para que essa comunicação dê certo, o sistema usa regras universais chamadas protocolos:Endereço IP: A identificação única de cada aparelho na rede, como se fosse o CEP de uma casa.Pacotes de dados: Seus arquivos (como uma foto) são divididos em pedacinhos, viajam por rotas diferentes e se juntam novamente no destino.Roteadores: Equipamentos que guiam esses pacotes pelo melhor caminho até o destino.Internet vs. Web (WWW)Muitas pessoas acham que internet e web são a mesma coisa, mas elas são tecnologias diferentes:Internet: É a estrada física (os cabos, os computadores e a infraestrutura).Web (World Wide Web): É uma das coisas que roda dentro dessa estrada. Ela é o sistema de páginas, sites, links, HTML, CSS e JavaScript que você acessa pelo navegador. Outros serviços como aplicativos de banco, jogos online e e-mails usam a internet, mas não fazem parte da web.
